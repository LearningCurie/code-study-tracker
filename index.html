How each topic works

The same three-step loop runs through both trackers.

  1. Learn

    Read one article and watch one video from the topic's study panel. Write the core moves from memory.

  2. Apply

    Solve in order, Easy to Hard. Say the brute force first, then find the better approach without hints.

  3. Review

    Mark each item. Filter by what needs practice and redo it a week later until it sticks.
